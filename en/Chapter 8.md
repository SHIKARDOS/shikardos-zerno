# CHAPTER 8. THE GRAIN MAP: FUNCTIONAL DESCRIPTION, CLASSIFICATION, AND DECOMPOSITION OF SOLUTIONS

## 8.1. The purpose of the Grain Map

The Grain Map is the ordered result of the collection stage: a summary of the found elements, described through the functions they perform. Its purpose is to make the collected material fit for synthesis.

The collected specimens from different fields are outwardly incommensurable: a sponge, a pump membrane, a compression algorithm, and an organizational rule share no common appearance. Comparing them directly is impossible. The Grain Map solves this difficulty by translating each solution from the language of things into the language of functions: outward dissimilarity yields to functional comparability.

The map performs three tasks. First, it fixes what has been collected in a form admitting verification of the source. Second, it groups solutions by function, revealing which functions already have many variants and which have only a few. Third, it prepares the material for synthesis: it is from the map that the grains entering the future system are chosen.

## 8.2. Functional description: from thing to function

The central operation of the map is the translation of a solution from the description of "what it is" to the description of "what it does". A grain is formulated not through material and not through outward form, but through the function and the mechanism of its performance.

The functional description contains three obligatory parts:

1. **Function** — what the element does, what task it solves (for example, "accumulates energy", "divides a flow", "maintains stability").
2. **Mechanism** — in what way the function is performed (for example, "through elastic deformation", "through gravitational selection").
3. **Constraints** — under which conditions the mechanism works and where it stops working.

The function answers "what for", the mechanism "how", the constraints "when". Only a complete three-part description makes a grain fit for comparison and transfer: the researcher sees not only what to borrow but also under which conditions the borrowing will retain force.

The transition from thing to function requires effort, and in it lies the main intellectual labor of the stage. One and the same device may be described by several functions — for example, a wheel simultaneously "transmits load" and "reduces friction". The choice of function is determined by the task definition: the grain is extracted for a concrete goal, not "in general".

## 8.3. Classification of functions

For the map to be surveyable, functions are grouped into classes. The following working classification is proposed, based on the type of transformation:

- **Movement** — functions connected with carrying something in space: transportation, direction, holding on a path.
- **Transformation** — functions changing form, state, or kind: transformation of energy, material, signal.
- **Accumulation** — functions of preservation and storage: storing energy, substance, information.
- **Regulation** — functions of controlling a quantity: amplification, weakening, stabilization, feedback.
- **Joining and separation** — functions establishing or breaking a link: fastening, filtration, isolation.
- **Protection** — functions guarding against external influence: shielding, redundancy, damping.

This classification is not exhaustive and does not claim strict uniqueness. It serves as a working tool: it helps to see in which classes of functions the map is saturated and in which it is empty. An empty class is a signal for additional collection, not a reason to ignore it.

One and the same element may fall into different classes depending on the chosen function. This is not an error of the map but a reflection of the many-sidedness of solutions: the wheel realizes both movement and the reduction of friction. The map admits multiple classification on condition that each record indicates which function exactly is considered.

## 8.4. Decomposition: breaking a solution into grains

A complex solution rarely represents one grain. Usually it is a system of several functional elements, each deserving a separate record.

Decomposition is the breaking of a found specimen into its constituent functions. The steam engine breaks into the grain of "transforming heat into motion" and the grain of "transmitting motion", each of which can be borrowed independently. The rule of decomposition: the breaking continues until each singled-out element carries one discernible function.

The depth of decomposition is determined by the task. Too coarse a breaking misses transferable functions; too fine a breaking crushes the whole into fragments losing independent meaning. The criterion of depth is simple: a grain is singled out at the level at which its function can be transferred into another solution as a self-contained one.

Decomposition reveals an important property of collection: one found specimen may yield several grains. Therefore the completeness of collection is measured not by the number of sources but by the number and diversity of extracted functions.

## 8.5. The structure and format of the map

The Grain Map is kept as an ordered table. For each grain the following fields are fixed:

- **identifier** — a stable designation of the grain;
- **function** — the formulation of the task performed;
- **mechanism** — the way the function is performed;
- **constraints** — the conditions of applicability;
- **source** — where the specimen was taken from;
- **function class** — the membership in a classification class;
- **search direction** — historical, horizontal, or abstract.

The unity of the format ensures the comparability of records and the possibility of machine processing. The map may be kept manually or programmatically — the format does not depend on the carrier.

The tabular form must not hide the main thing: the map is not an archive but a working tool. It is revised as the work advances: new findings are added, wrongly extracted grains are corrected, empty classes are marked as a signal for additional collection.

## 8.6. The rules of keeping the map

The map obeys rules arising from its purpose.

The first rule is **completeness of the record**: a grain without the source and constraints is not considered entered. An undocumented record is indistinguishable from a conjecture.

The second rule is **functional purity**: a grain is described by a function, not by outward appearance. The record "a beautiful device" is not a grain.

The third rule is **one function — one record**: if several functions are extracted from a specimen, each receives a separate record.

The fourth rule is **reversibility**: any record may be refined or corrected when new data appears. The map is not a summary of final truths; it is the current state of the research.

The fifth rule is **the separation of fact and evaluation**: the map fixes what the element does and how, but not "whether it is good". Evaluation belongs to the stage of verification, not to the stage of description.

Observance of these rules makes the Grain Map a reliable foundation for the next stage — synthesis. The map shows from what one can build; how exactly to build is determined by Chapter 9.
