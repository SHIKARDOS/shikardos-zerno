# CHAPTER 9. FORMALIZATION OF THE 合 (SYNTHESIS) STAGE

## 9.1. The purpose of the synthesis stage

Synthesis is the transition from a set of grains to a holistic system. If collection answered the question "from what can one build", synthesis answers "how to build a whole from this".

The central danger of the stage is the reduction of synthesis to a simple combination. Joining elements mechanically is not hard, but mechanical joining does not engender a new quality: it merely adds what already exists. The task of synthesis is not to list grains side by side, but to build between them such relations that a whole arises, exceeding the sum of its parts.

Synthesis is therefore work not so much with elements as with links. The grains have already been collected and described; now it is decided which of them to join, by which links, and for the sake of which function of the whole.

## 9.2. The selection of grains for synthesis

Not all collected grains will enter the future solution. The Grain Map is deliberately redundant: it contains variants from which synthesis chooses.

Selection is made by three criteria arising from the task definition. The first is **functional necessity**: the grain realizes a function required by the target solution. The second is **compatibility**: the grain is able to work in conjunction with the other selected grains. The third is **overcoming constraints**: the grain permits bypassing a constraint imposed by the task or by other elements.

Selection is not a one-time decision. As the structure is built, some grains fall away as incompatible, others return from the map as newly needed. Selection and construction proceed jointly, refining each other.

It is essential that selection is recorded: for each included grain it is written which function it carries in the new system, and for each rejected grain why it did not enter. This preserves the reproducibility of synthesis and permits checking the soundness of the choice.

## 9.3. Analysis of compatibility and contradictions

Before joining, one must check whether the elements are joinable. The analysis of compatibility reveals whether the grains can work in one system without destroying each other.

Compatibility is checked along three aspects. **Functional compatibility** — whether the functions of the elements perform mutually complementary, and not mutually exclusive, tasks. **Compatibility of conditions** — whether the constraints under which the mechanisms work overlap. **Resource compatibility** — whether the elements compete for one and the same resource to the point of destroying the system.

Special attention is given to contradictions. A contradiction arises when the requirements of one function come into conflict with the requirements of another. A contradiction is not a verdict on the solution; in the TRIZ tradition it is treated as a source of development. But a contradiction must be identified and formulated explicitly, otherwise it will manifest itself already after realization — at the stage of verification, where correcting is dearer.

The analysis of compatibility performs the function of early screening: it eliminates unproductive combinations before the costly stage of embodiment. This is the practical sense of the hypothesis that the analysis of compatibility raises productivity.

## 9.4. Building links: from a set to a structure

Synthesis is completed by the building of a structure — the explicit setting of links between grains. A set of elements turns into a system when it is indicated how each element is linked with the rest and what role it plays in the whole.

Links are set functionally: element A is linked with element B if the result of A's function serves as the input or the condition for B's function. For example, the grain of "energy accumulation" is linked with the grain of "transforming energy into motion" if the first feeds the second. A link is described not as spatial proximity but as functional dependence.

The building of a structure is an iterative process. The researcher advances a variant of the structure, checks it for completeness (are all required functions covered) and for consistency (are there no insoluble contradictions), and refines it until the structure becomes workable.

A useful device is the representation of the structure as a graph, where the vertices are grains and the edges are functional links. Such a representation makes synthesis surveyable and admits verification: the absence of a link with the common structure means a "dangling" element that performs no function in the whole.

## 9.5. The criterion of wholeness: not a mechanical combination

The result of synthesis is recognized as a holistic system, and not a mechanical combination, if three conditions are met.

The first is **functional completeness**: the structure covers all functions required by the task definition.

The second is **connectedness**: each element is linked with the whole; in the structure there are no isolated grains included "just in case".

The third is **emergent quality**: the system as a whole performs a function or possesses a property that none of the grains has separately. It is this third condition that distinguishes synthesis from simple addition and is the criterion of the accomplished transition 合 → 生.

If the third condition is not met, synthesis is not completed: only a combination, and not a new whole, has been built. Such a solution is not automatically discarded — it may be useful — but it is not a result of the Grain Principle in the full sense, and this must be recorded honestly.

## 9.6. The synthesis procedure: steps

Synthesis is performed in the following sequence.

**Step 1. Determine the required functions.** From the task definition a list is written out of the functions that the target solution must perform.

**Step 2. Match grains to functions.** To each required function are matched the grains from the map capable of realizing it.

**Step 3. Check compatibility.** For the assumed set, conflicts and incompatibilities are revealed; insoluble ones are removed by replacing grains.

**Step 4. Build the structure.** Between the selected grains functional links are set, forming the graph of the solution.

**Step 5. Check wholeness.** The structure is checked for completeness, connectedness, and the presence of emergent quality.

**Step 6. Record the result.** The description of the structure, the selection of grains, and the links are fixed so that the solution can be reproduced and verified.

The result of the stage is not a ready thing but its functional structure — a description of which grains and links compose the solution. The embodiment of this structure in a concrete form constitutes the next stage — birth, considered in Chapter 10.
